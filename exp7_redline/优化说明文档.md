# 巡线小车代码优化说明文档

## 📌 版本概述

| 版本 | 状态 | 核心问题 |
|------|------|----------|
| **初版** | ❌ 无法巡线 | 单传感器 if-else 离散判断，开环固定比例转向，电机方向控制不完整 |
| **优化第一版** | ✅ 能巡线但摆头 | 8 传感器融合 + 级联 PID，但转向增益过大导致振荡 |
| **当前版本** | ✅ 稳定巡线 | 调优后的参数，兼顾转弯能力和直线稳定性 |

---

## 一、初版代码的问题根源

### 1.1 初版巡线逻辑

```cpp
// 初版：逐条判断单个传感器
if (digitalRead(L1) == HIGH) { target1 = V * 0.9;  target2 = V * 0.5; }  // 低右转
if (digitalRead(L6) == HIGH) { target1 = V * 0.5;  target2 = V * 0.9; }  // 低左转
if (digitalRead(L2) == HIGH) { target1 = V * 0.75; target2 = V * 0.15; } // 中右转
// ...
```

### 1.2 为什么注定失败

```
初版思路：
  "L2 传感器看到黑线 → 执行中右转（速度比 0.75:0.15）"

致命缺陷：
  1. 离散判断 → 只知道"偏了"，不知道"偏了多少"
  2. 开环控制 → 无论偏差大小都用同一个固定比例
  3. 无反馈校正 → 弯道曲率一变就失效
  4. 多传感器触发时 → 只执行第一个匹配的 if（后续被跳过）
  5. 无传感器滤波 → 单次读数噪声即可触发误判
```

### 1.3 其他具体 bug

| 位置 | 问题 | 影响 |
|------|------|------|
| `control()` 第 45 行 | `L5\|\|L5` 重复判断，应是 `L4\|\|L5` | 直线检测不准 |
| `setup()` | `DIR2` 从未设为 `OUTPUT` | 右电机方向不确定 |
| `control()` | 始终用 `abs(output)` 输出 PWM，不改变方向 | 电机只能单向转 |
| `loop()` | 无任何状态管理 | 上电即跑，无启停控制 |

## 二、优化思路：从"离散触发"到"连续闭环"

### 2.1 核心理念转变

```
初版：传感器触发 → 固定动作（开环）
      L1触发 → 0.9:0.5速度比
      L2触发 → 0.75:0.15速度比
      ↑ 离散、无反馈、不连续

优化版：传感器阵列 → 连续位置偏差 → 转向PD → 差速量 → 速度PID → 电机
        8路加权融合   偏差=+1.3     delta=1.8   左轮减速1.8  精确执行
        ↑ 连续、有反馈、自适应
```

## 三、代码逐模块详解

### 3.1 红外数据采集与滤波（`updateInfrared`）

```cpp
volatile int infrared[8][2] = {0};  // 8路传感器 × 2帧历史

void updateInfrared() {
  int sensorPins[8] = {L1, L2, L3, L4, L5, L6, L7, L8};
  for (int i = 0; i < 8; i++) {
    for (int j = 1; j > 0; j--) {
      infrared[i][j] = infrared[i][j - 1];  // 旧数据后移
    }
    infrared[i][0] = digitalRead(sensorPins[i]);  // 读新值
  }
}
```

**作用：** 每个传感器保留最近 2 次读数（当前帧 + 上一帧），后续取平均时抑制单次噪声。

**为什么 2 帧而不是更多？** 控制周期 20ms，2 帧=40ms 历史。帧数太多会引入滞后，导致对弯道反应变慢。2 帧是在"降噪"和"响应速度"之间的平衡。

---

### 3.2 位置偏差计算（`calcPositionError`）

```cpp
float calcPositionError() {
  float weight[8] = {-1.5, -0.8, -0.4, -0.1, 0.1, 0.4, 0.8, 1.5};
  float sum = 0;
  for (int i = 0; i < 8; i++) {
    float avg = (infrared[i][0] + infrared[i][1]) / 2.0;  // 2帧平均
    sum += avg * weight[i];
  }
  return sum;
}
```

**核心思想：**

```
传感器物理位置:  左1  左2  左3  左4  右5  右6  右7  右8
                  ↓    ↓    ↓    ↓    ↓    ↓    ↓    ↓
位置权重:       -1.5 -0.8 -0.4 -0.1 +0.1 +0.4 +0.8 +1.5
                                              
黑线在正中间 → 左右权重抵消 → 偏差 ≈ 0
黑线偏左     → 负权重传感器触发 → 偏差 < 0（负值=偏左）
黑线偏右     → 正权重传感器触发 → 偏差 > 0（正值=偏右）
```

**为什么要"连续"？** 偏差量的大小直接反映偏离程度——略微偏左（偏差≈-0.3）和严重偏左（偏差≈-1.2）输出的差速量不同，实现了**按需转向**。

**权重设计原则：**
- 中间传感器权重小（±0.1）：小幅修正，保持直线稳定
- 边缘传感器权重大（±1.5）：大幅修正，应对急弯
- 最边缘不超过 DELTA_MAX 对应的有效范围，防止过度反应

---

### 3.3 转向 PD 控制器（`steerPD`）

```cpp
float steerPD(float error) {
  float u = STEER_KP * error + STEER_KD * (error - last_position_error);
  last_position_error = error;
  if (u > DELTA_MAX) u = DELTA_MAX;
  if (u < -DELTA_MAX) u = -DELTA_MAX;
  return u;
}
```

**P 项（比例）：** `STEER_KP × 当前偏差`
- 偏差越大 → 转向越猛
- 这是转向的"主力"

**D 项（微分）：** `STEER_KD × 偏差变化量`
- 偏差在增大 → D 项增强转向（加速响应）
- 偏差在减小 → D 项抑制转向（提前收力，防止过冲）
- 这是转向的"减震器"

**为什么用 PD 而不是 PID？** 位置偏差不需要积分项（I）。加入 I 会导致：
- 在弯道中持续累积 → 出弯时过度转向
- 在直线段微小的稳态偏差被放大 → 反而诱发振荡

**限幅（DELTA_MAX）：** 防止差速量超过安全范围。当前 DELTA_MAX=2.0，基础速度 V=3.0，所以最急转弯时内侧轮速 = 3.0 - 2.0 = 1.0，仍保持前行，不会完全停转。

---

### 3.4 差速分配

```cpp
if (delta_speed > 0) {
  // 偏左（需右转）→ 减速左轮
  target1 = V - abs(delta_speed);
  target2 = V;
}
else if (delta_speed < 0) {
  // 偏右（需左转）→ 减速右轮
  target1 = V;
  target2 = V - abs(delta_speed);
}
else {
  // 正中 → 直行
  target1 = V;
  target2 = V;
}
```

**物理直觉：**
```
delta_speed = +1.5：左轮 V-1.5=1.5, 右轮 V=3.0 → 右侧快 → 车右转 ✓
delta_speed = -2.0：左轮 V=3.0,   右轮 V-2.0=1.0 → 左侧快 → 车左转 ✓
delta_speed = 0：   左轮 V=3.0,   右轮 V=3.0     → 同速 → 直行 ✓
```

---

### 3.5 丢失恢复机制

```cpp
else {  // isAllWhite() == true
  if (delta_speed > 0 && delta_speed < DELTA_MAX)
    delta_speed += 0.12 * V;   // 保持右转趋势并加强
  else if (delta_speed < 0 && delta_speed > -DELTA_MAX)
    delta_speed -= 0.12 * V;   // 保持左转趋势并加强
}
```

**场景：** 小车完全偏离赛道，8 个传感器全部看到白色地面。

**策略：** "猜着往回走"——保持丢失前最后一刻的转向方向，逐步增强。这在赛道外侧偏离时尤其有效：如果小车偏右冲出去了，丢失前 delta_speed 是负值（正在左转回线），继续保持左转，慢慢就能找回黑线。

---

### 3.6 速度 PID 控制器

```cpp
int pidController1(float targetVelocity, float currentVelocity) {
  ek10 = targetVelocity - currentVelocity;
  u1 = u1 + q0*ek10 + q1*ek11 + q2*ek12;  // 位置式PID
  // 限幅 ±255
  ek12 = ek11; ek11 = ek10;  // 误差历史更新
  return (int)u1;
}
```

**位置式 PID 公式：**
```
u(k) = u(k-1) + q0×e(k) + q1×e(k-1) + q2×e(k-2)

其中: q0 = Kp(1 + T/Ti + Td/T)
      q1 = -Kp(1 + 2Td/T)
      q2 = Kp×Td/T
```

**作用：** 精确跟踪目标速度。当转向 PD 要求左轮从 3.0 降到 1.5，速度 PID 负责让左轮实际速度快速稳定到 1.5。

**为什么保留原有的两个独立 PID？** 两个电机物理特性可能不同，独立 PID 各自调节更精确。

---

### 3.7 电机方向控制

```cpp
// 左电机
if (output1 > 0) { digitalWrite(DIR1, HIGH); analogWrite(PWM1, output1); }
else             { digitalWrite(DIR1, LOW);  analogWrite(PWM1, abs(output1)); }

// 右电机（物理反向安装）
int output2 = pidController2(-target2, velocity2);  // 注意负号
if (output2 > 0) { digitalWrite(DIR2, HIGH); analogWrite(PWM2, output2); }
else             { digitalWrite(DIR2, LOW);  analogWrite(PWM2, abs(output2)); }
```

**右电机的负号：** 右电机物理安装方向与左电机相反，所以目标速度取反（`-target2`）。正常前进时，PID 输出为负值 → DIR2=LOW → 电机正转。这是硬件决定的约定，不需要修改。

---

### 3.8 状态机

```
┌──────────┐    isAllBlack()     ┌──────────┐
│  巡线中   │ ─────────────────→ │  已停车   │
│ isFinish │                    │allFinish  │
│ = false  │                    │ = true    │
└──────────┘                    └──────────┘
```

- `isTracing`：`control()` 的总开关，为 false 时不执行任何控制
- `isFinish`：`control()` 中检测到全黑后置 true，目标速度归零
- `allFinish`：`loop()` 中确认停车完成，防止重复执行停车逻辑

## 四、参数调优指南

### 4.1 参数总览

```
┌─────────────────────────────────────────────────────────────────┐
│                       参数分层结构                                │
├───────────────┬──────────┬──────────┬──────────────────────────┤

├───────────────┼──────────┼──────────┼──────────────────────────┤
│ 基础设定       │ V        │ 3.0      │ 直行时的基础速度            │
│               │ PERIOD   │ 20       │ 控制周期(ms)               │
├───────────────┼──────────┼──────────┼──────────────────────────┤
│ 外环：转向PD   │ STEER_KP │ 5.0      │ 偏差→差速的比例增益        │

│               │ Td       │ 10.0     │ 微分时间常数                │
│               │ 平滑系数  │ 0.8/0.2  │ 目标速度低通滤波            │

```

### 4.2 症状 → 调参速查表

| 症状 | 诊断 | 调整方向 | 具体操作 |
|------|------|----------|----------|
| 🐍 **左右摆头/振荡** | 转向增益过大 | ↓ 降低增益 ↑ 增大阻尼 | `STEER_KP` 降 1.0；`STEER_KD` 升 0.2；`DELTA_MAX` 降 0.5 |
| 🐌 **转弯不够力/冲出赛道** | 转向增益过小 | ↑ 增大增益 | `STEER_KP` 升 1.0；`DELTA_MAX` 升 0.5 |
| 🐢 **直角弯转不过来** | 差速量上限不够 | ↑ 允许更大差速 | `DELTA_MAX` 升 0.5（注意不要超过 V） |
| 🐛 **直线段也小幅度摇摆** | 权重中间跨度过大 或 STEER_KD 不足 | 收窄中间权重 或 ↑ D | 中间权重从 ±0.1 改为 ±0.05；`STEER_KD` 升 0.2 |
| 🐘 **转弯反应慢半拍** | 平滑滞后太大 或 Kp 太小 | ↓ 减小平滑 ↑ 加速响应 | 平滑系数改为 0.9/0.1；`Kp` 升 2.0 |
| 🦘 **丢线后找不回来** | 丢线恢复速率不够 | ↑ 增大恢复速率 | 丢线恢复系数从 0.12 升到 0.18 |
| 🦋 **丢线后甩到相邻弯道** | 丢线恢复速率太大 | ↓ 减小恢复速率 | 丢线恢复系数从 0.12 降到 0.08 |
| 🦀 **电机一顿一顿** | 速度 PID 响应太慢 或 积分不足 | ↑ Kp ↓ Ti | `Kp` 升 2.0；`Ti` 降 10 |
| 🦞 **电机高频啸叫** | 速度 PID 过于激进 | ↓ Kp ↑ Td | `Kp` 降 2.0；`Td` 升 5.0 |
| 🐳 **终点线不识别** | 全黑阈值太严格 | 检查传感器 | 确认赛道终点线是黑色；检查红外读数（白色=0 黑色=1？） |

### 4.3 调参原则

```
1. 每次只改一个参数，测试后再改下一个
2. 改幅从小到大：STEER_KP 每次 ±1.0，STEER_KD 每次 ±0.2，DELTA_MAX 每次 ±0.5
3. 先调外环（转向），后调内环（速度）
4. 速度 PID 参数（Kp/Ti/Td）对稳定性影响最大，谨慎调整
5. 记录了每次改动和测试结果，方便回溯
```

### 4.4 专项场景调优

#### 场景一：赛道有连续 S 弯

如果小车在第一个弯转向不足、第二个弯转向过度，说明转向响应与车身长度/轴距不匹配。

**调整：** 增大 `STEER_KD`（0.8 → 1.0~1.2），增强阻尼，让每次转向后更快回正。

#### 场景二：赛道有直角弯

直角弯需要瞬间大幅转向。

**调整：** 增大 `DELTA_MAX`（2.0 → 2.5），同时增大边缘权重（±1.5 → ±2.0），让最外侧传感器触发时差速量更大。

#### 场景三：赛道光线不均匀

光照变化导致红外读数不稳定。

**调整：** 增大 `IR_HISTORY`（2 → 3），更多帧历史平均抑制光照噪声。注意这会让响应变慢，需要同步略微增大 `STEER_KP` 补偿。

#### 场景四：电池电量变化

电量降低 → 同样 PWM 占空比下电机转速下降 → 速度 PID 跟踪不上了。

**调整：** 增大 `Kp`（7.0 → 10.0），让速度环更快补偿电压下降。

## 五、调试技巧

### 5.1 串口监控

当前 `loop()` 中打印左右轮实际速度：

```cpp
Serial.print(velocity1); Serial.print("\t");
Serial.println(velocity2);
```

**怎么看：**
- 直线上两轮速度应该接近，差值 < 0.5
- 转弯时内外轮速度差应与弯道曲率匹配
- 如果两轮速度剧烈跳动 → 速度 PID 过激进，增大 Td 或降低 Kp

### 5.2 增加调试输出

如果遇到难以定位的问题，可以在 `control()` 中临时增加：

```cpp
Serial.print("err:"); Serial.print(position_error);
Serial.print("\tdelta:"); Serial.print(delta_speed);
Serial.print("\tt1:"); Serial.print(target1);
Serial.print("\tt2:"); Serial.println(target2);
```

注意：`control()` 运行在定时器中断中，大量 `Serial.print` 会拖慢控制周期。调试时可以将 `PERIOD` 临时增大到 50ms。

### 5.3 逐步测试法

1. 先让小车在直线上跑，确认不摆头（调 STEER_KP/KD）
2. 再让小车过单个缓弯，确认转弯流畅（调 DELTA_MAX）
3. 最后跑完整赛道，确认所有弯道都能通过（微调权重和恢复速率）
